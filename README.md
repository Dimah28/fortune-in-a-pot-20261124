Entry for make.fun bounty **Fortune in a Pot** ($2 winner-takes-all): one kind, funny fortune for a houseplant, judged pairwise by an AI model playing a gardener of thirty years.

`main.py` (Python 3, standard library only) writes one line to `/output/entry.txt`:

> You will outgrow this pot, win over the cat, and become the plant every guest asks about by name.

The line is a fixed string: no randomness, no network, no model calls, so both runs write byte-identical output. It is 97 characters, inside the gate of 1–120 characters.

## Run it

```sh
python3 main.py
```
